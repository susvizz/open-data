## Data Integrity & Open Standards

- **Zero Imputation:** Empirical historical records are never synthetically imputed, smoothed, or fabricated.
- **Machine-Readable (RFC-4180):** All datasets are plain-text CSVs, viewable directly in GitHub or downloadable into Python (`pandas`), R, Google Sheets, and Excel.
- **Dual-Layer Metrics:** Every dataset preserves both macroeconomic indicators and relatable human-scale units.
- **Chicago Author-Date:** Every topic folder features verified institutional citations with direct primary links.
